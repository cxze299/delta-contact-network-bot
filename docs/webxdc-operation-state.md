# 小程序操作与多网络状态

每次用户操作只提交一个请求。点击后立即显示处理中；服务端成功回执到达后才更新业务结果。

- 准备：验证输入并生成不可重复的请求编号，禁止第二个写操作。
- 提交中：将绑定当前网络和当前步骤的请求交给 Delta Chat。
- 等待回执：客户端接收成功不等于业务成功。
- 结果未确认：3 秒没有回执时保存未确认状态并解除页面等待；不自动重发、不自动取消、不提前报告成功，相同未确认操作不会重复提交。
- 完成或失败：仅匹配当前请求编号的回执解除等待；结果提示显示 3 秒。加入码等需要读取的数据保留至关闭。

后续服务器状态包含该实例最近的处理结果，用于核对已完成的未确认操作；重新打开页面不自动发送。初始化不额外发送刷新或目录请求；服务端快照已包含目录。

一个账号可以在多个网络保留独立成员资料。当前网络切换后立即更新页面并清除旧网络展开状态。旧网络的写请求由服务端拒绝；只读刷新允许恢复新状态。取消加入必须提供当前加入步骤令牌，只删除该步骤，不能取消新步骤或退出原网络。Core 提供序号时忽略乱序的旧状态快照。

验证：服务端测试覆盖多网络加入、切换、旧网络写入拒绝、精确取消及已存结果恢复；浏览器配合真实状态机故意丢弃回执，确认操作不重发、界面可返回，后续状态可核对结果。此测试不替代 Delta Chat 真机和中继环境验证。

已验证系统管理密钥的账号可以从“我的网络”或管理页选择“加入此网络”，无需复制加入码。已有资料时复用昵称，但仍明确确认当前账号和本网络隐私设置；确认前不创建成员、不切换网络。该入口服务端验证密钥授权，确认时再次验证，网络停用或禁止加入仍会拒绝。普通成员继续使用加入码，不接受网络名称作为凭证。

补充验证：手机宽度 390 px 下，真实后端配合浏览器完成直接加入第二网络、取消返回、两网络切换；后端覆盖密钥撤销、停用、禁止加入、无成员资料的新管理员及重复确认。

管理页面优先使用已接收的完整状态即时展示；上下文缺失才请求初始化。等待回执时仍可返回上一页，未确认请求继续保留，不自动重发或伪报完成。打开管理页面不再自动滚动离开页首。

加入网络的新版入口是本地表单，打开、编辑与返回不发送消息。成员一次提交加入码、昵称和本网络隐私选择；服务端在同一事务中验证凭证、创建成员、绑定当前账号并切换网络。错误不改变原成员资格，重复加入保留原资料；旧版分步接口仍为旧包兼容保留。管理员可在表单选择已授权的网络，服务端仍校验账号的密钥授权。加入错误的固定说明随该请求结果保存，后续状态可以精确恢复迟到的反馈，不保存输入的加入码。

验证包括普通账号连续加入五个网络、错误码、失败限流、重复投递、资料隔离及管理员权限；浏览器验证本地打开/返回零请求和 4.5 秒延迟回执后单次加入成功。
