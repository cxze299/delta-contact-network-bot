# 小程序操作与多网络状态

每次用户操作只提交一个请求。点击后立即显示处理中；服务端成功回执到达后才更新业务结果。

- 准备：验证输入并生成不可重复的请求编号，禁止第二个写操作。
- 提交中：将绑定当前网络和当前步骤的请求交给 Delta Chat。
- 等待回执：客户端接收成功不等于业务成功。
- 结果未确认：3 秒没有回执时保留原请求，提示手动重试；不自动重发，不自动取消，不提前报告成功。
- 完成或失败：仅匹配当前请求编号的回执解除等待；结果提示显示 3 秒。加入码等需要读取的数据保留至关闭。

手动重试沿用原请求编号与密文，服务端返回已保存的结果而不重复执行。重新打开页面不自动发送。初始化也不额外发送刷新或目录请求；服务端快照已包含目录。

一个账号可以在多个网络保留独立成员资料。当前网络切换后立即更新页面并清除旧网络展开状态。旧网络的写请求由服务端拒绝；只读刷新允许恢复新状态。取消加入必须提供当前加入步骤令牌，只删除该步骤，不能取消新步骤或退出原网络。Core 提供序号时忽略乱序的旧状态快照。

验证：服务端测试覆盖多网络加入、切换、旧网络写入拒绝、精确取消及旧回执重放；浏览器配合真实状态机故意丢弃首次回执，确认 16 秒仅发送一次，手动重试后恢复并可取消返回原网络。此测试不替代 Delta Chat 真机和中继环境验证。

已验证系统管理密钥的账号可以从“我的网络”或管理页选择“加入此网络”，无需复制加入码。已有资料时复用昵称，但仍明确确认当前账号和本网络隐私设置；确认前不创建成员、不切换网络。该入口服务端验证密钥授权，确认时再次验证，网络停用或禁止加入仍会拒绝。普通成员继续使用加入码，不接受网络名称作为凭证。

补充验证：手机宽度 390 px 下，真实后端配合浏览器完成直接加入第二网络、取消返回、两网络切换；后端覆盖密钥撤销、停用、禁止加入、无成员资料的新管理员及重复确认。
