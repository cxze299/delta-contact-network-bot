# 联系人网络小应用（0.4.0）

这是 Delta Chat 私聊里的 Webxdc 小应用，不需要网页账号，也不直接访问 NAS HTTP 接口。

## 四个入口

- 首页：开始/继续引导、刷新。新成员依次填写加入码、昵称、确认隐私说明、选择分享地址和公开范围。
- 找人：输入昵称或编号，点击搜索结果，填写联系理由，确认本次分享。可以查到自己隐藏的资料，但不能申请联系自己。
- 申请：显示最近 20 条本人当前网络申请，点击同意、拒绝或撤销。同意后再次确认分享地址，双方再去 Delta Chat 添加好友。
- 我的：资料、隐私、网络切换、加入新网络、屏蔽举报、退出和删除。退出/删除使用服务端确认步骤。

## 怎么打开

更新后的机器人在新成员完成加密安全加入时发送专属小应用。已有用户可将 dist/联系人网络.xdc 发到机器人私聊并打开，点“开始 / 继续引导”生成“小程序”消息，确认发送，机器人会返回专属版本。也可在原私聊发送一次“小程序”。之后不用记指令。

每次按钮操作会准备一条消息草稿。需要选择原机器人私聊并点 Delta Chat 的发送按钮；随后重新打开专属小应用查看结果。这是 Webxdc sendToChat 的接口限制，不是微信式静默提交。不要删除草稿后误以为操作完成。

普通消息仍会发送至私聊，作为反馈和同步失败时的可读结果。小应用刷新只重新读取状态，不代表申请已送达或对方已添加好友。

## 管理员

“我的”页面底部按权限显示管理入口。网络管理员可管理当前授权网络的成员、加入码、举报和操作记录；系统管理员另有创建网络、任免管理员、停用/恢复网络等入口。部分管理表单仍需填写成员或网络编号，可点管理帮助查看格式。隐藏入口不构成权限控制，所有管理操作复用服务端权限校验。

## 安全边界

- 包内的随机实例令牌同时绑定服务端核验的发送者、账号和原私聊；不能用 selfAddr 或状态更新内的自报身份执行操作。
- 操作必须通过加密私聊传入，网络上下文和确认步骤须匹配，重复请求编号不会重复执行。
- 状态更新没有独立的发送者身份字段，因此仅在原机器人双人私聊使用；最终授权信息请核对机器人私聊消息。不要转发专属小应用，它的历史可能包含已授权联系方式。
- Webxdc 历史和聊天记录在用户设备上，服务端删除不能远程清除。服务端申请内容仍按原有保留机制清理。
- 普通安装包没有成员、加入码或凭据。专属包只有实例令牌，成员资料由后续私聊状态更新提供。

## 验证与部署

本地自动测试使用模拟 RPC 验证业务接入边界，不能替代真实 Delta Chat 客户端验证。已核对安装的 deltachat2 RPC 方法和官方 sendToChat / setUpdateListener 文档；客户端打开、草稿发送、状态更新以及跨设备表现仍需实际使用确认。本次按要求不做真实账号联调。

版本 0.4.0 使用同一 SQLite 数据库和专用机器人账号，启动时新增 xdc_instances、xdc_requests 表。更新前保存旧镜像和 compose 文件；回滚到旧镜像时新增表可以保留，不删除现有成员数据。
