# Bun 迁移工作区（开发中，不可部署）

这是与现有服务隔离的实验工程，尚无 RPC 连接、身份验证、完整业务、网页后台、前端接入或双轨通信，不能替换生产服务。

目前包含严格协议校验、SQLite 事务和请求去重基础，以及以测试用户为上下文的多网络加入、切换、退出原型。原型缺少速率限制、角色权限、最后管理员保护等必要功能，不能面向用户运行。游标目前独立于业务事务，尚未实现完整消费流程。

运行：`bun install --frozen-lockfile`，然后 `bun run typecheck` 和 `bun test`。现有用户允许重建业务测试数据；机器人 Core 账号、认证凭据和现行服务需要保留，正式切换前需真实客户端与隔离环境的端到端验证。
