# 私聊操作指南

所有操作都在机器人私聊中完成。新成员添加并验证机器人后，机器人会主动发送欢迎说明。成员按照每一步的问题回复内容或中文文字选项即可。任何引导步骤都可输入 `q` 退出。群聊消息不会触发业务操作，也不会发送小应用。

## 成员操作

默认引导流程：

```text
回复管理员提供的加入码
回复昵称
发送“查找好友”
回复对方昵称
回复结果前的数字编号，联系人名片立即发送给对方
```

主菜单不再提供按成员编号查找。发送“查看资料”后，可发送“修改昵称”“修改介绍”或“返回菜单”；输入 `q` 退出当前步骤。

主菜单发送“加入新网络”后，依次回复新网络的加入码和昵称。同一账号可以同时保留多个网络成员身份，新加入的网络会成为当前网络。发送“帮助”才会显示完整文本指令表；其他普通消息显示简洁引导菜单。

管理员创建或更换网络时直接回复自定义加入码。加入码可包含中文、空格、符号或表情，长度只受 Delta Chat 单条消息上限约束。加入码是入网凭证，应通过可信渠道发送。

加入后昵称默认可查找并可接收好友申请。常用设置：

```text
编辑昵称 新昵称
编辑介绍 设计组成员
设置联系方式 name@example.org
公开资料
接收申请
```

查找与申请：

```text
查找 小明
申请 MABC123 我们在同一个项目组
确认 机器人返回的确认码
我的申请
```

收到申请后：

```text
同意申请 RABC1234
确认 机器人返回的确认码
```

也可以发送 `拒绝申请 RABC1234`。联系方式只会在接收方最后确认后分别发送给双方。

隐私和安全操作：

```text
隐藏资料
暂停申请
屏蔽 MABC123
屏蔽列表
解除屏蔽 MABC123
举报 MABC123 持续发送骚扰信息
退出网络
删除我的数据
```

`退出网络`只退出当前网络；`删除我的数据`清理所有网络中的业务资料。两项操作都需要确认。

多网络使用 `我的网络` 查看列表，使用 `切换网络 NABC123` 切换。之后的查找、申请和个人资料操作均针对当前网络。

## 更换账号后恢复

在新的 Delta Chat 账号中添加机器人，然后发送：

```text
恢复账号
```

按提示输入原成员编号。如果同一编号出现在多个网络中，再输入“网络编号 成员编号”。恢复申请 48 小时有效。成员编号不是密码，管理员必须在线下核实申请人身份后才能批准。批准后，原成员编号、昵称、资料、网络角色和成功联系记录迁移到新账号；机器人会自动重新发送仍为有效成员且双方未屏蔽的历史好友名片。

## 网络管理员

发送 `管理`查看菜单。网络管理员只管理当前网络：

```text
网络概况
查看加入码
成员列表
成员列表 小明
更换加入码
停用加入
恢复加入
移除成员 MABC123
封禁成员 MABC123 多次骚扰
解除封禁 MABC123
举报列表
处理举报 PABC1234 已警告并关闭
管理记录
恢复申请列表
批准恢复 VABC1234
拒绝恢复 VABC1234
```

更换加入码、移除和封禁需要确认。移除后成员可以再次使用有效加入码加入；封禁后同一账号不能重新加入。网络管理员不能移除或封禁其他管理员。

网络管理员只能查看和处理自己所管理网络的恢复申请。系统管理员可以处理全部网络。管理员应先通过可信的线下方式核实身份，不能把公开的成员编号本身当作身份证明。

## 系统管理员

系统管理员地址由服务器环境变量绑定。系统管理员可以：

```text
创建网络 网络名称
网络列表
切换网络 NABC123
修改网络名称 NABC123 新名称
任命管理员 NABC123 MABC123
撤销管理员 NABC123 MABC123
停用网络 NABC123
恢复网络 NABC123
```

创建网络和更换加入码返回敏感凭证，只能在加密私聊中操作。停用网络后，加入、查找和交换停止，未完成申请失效。
